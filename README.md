## 🎯 Objetivo do projeto

O objetivo deste projeto é desenvolver uma página HTML utilizando as principais tags estudadas em aula, apresentando informações sobre um filme de forma organizada e estruturada.

## 🛠️ Tecnologias utilizadas

* HTML5
* GitHub

## 📌 Descrição

A página apresenta informações sobre o filme *Homem-Aranha: Sem Volta para Casa*, incluindo seu ano de produção, diretor, duração, classificação, gênero, país de origem e uma breve sinopse. A página também possui uma imagem relacionada ao filme e um link para obter mais informações.
